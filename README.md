# 딜러 디렉터 (로그인 없는 판)

홀덤 토너먼트 **딜러 로테이션**을 자동으로 짜 주는 웹앱입니다. 설치·로그인 없이 브라우저에서 바로 씁니다.

## 여는 방법

- 이 폴더의 `index.html`을 브라우저(크롬·엣지)로 열면 됩니다.
- 깃허브 페이지로 올리면 주소 하나로 어디서나 열 수 있습니다 (저장소 설정 → Pages → main 브랜치).

## 할 수 있는 것

- 테이블 오픈·대기·깨기, 딜러 출근·퇴근·출근 예정
- 교대 간격(분)마다 자동 교대 — 오래 쉰 딜러부터 들어가고, 앉아 있던 딜러는 테이블을 옮기지 않음
- 로테이션 표: 앞으로의 교대를 미리 보여 주고, 칸을 끌어다 놓아 휴식·테이블을 바꿈
- 표 위 시각을 눌러 그 교대 시각만 바꾸기(이번만), 교대 때 테이블 사용 시작·대기·깨기 예약
- 명령 칸: `3시부터 15분 간격` · `1시에 7번 열어` · `다음 교대 5분 늦춰` · `김민수 어디야?` 같은 말
- 교대 예고 음성, 일시정지·재개, 되돌리기, 근무 시간 기록

## 알아 둘 것

- 이벤트는 **이 브라우저에만** 저장됩니다. 브라우저 기록을 지우면 사라지니, 보관하거나 다른 PC로 옮길 때는
  이벤트 목록 화면의 **백업 파일 저장 / 불러오기**를 쓰세요.
- 이 판에는 계정, 딜러 휴대폰 공유(QR), 여러 PC에서 같이 쓰기가 없습니다. 인터넷으로 아무것도 보내지 않습니다.
- 딜러 휴대폰 출근 체크가 없으므로, 새 이벤트는 **체크 없이 출근**이 켜져 있습니다 (출근 예정 딜러는 예정 시각에 투입).
